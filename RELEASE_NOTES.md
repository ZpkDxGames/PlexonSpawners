# PlexonSpawners 4.0.0 — WildStacker Authority Reset

PlexonSpawners 4.0.0 removes duplicate stacking ownership. WildStacker now owns every generic stacking concern; PlexonSpawners is limited to PlexonCraft recovery policy and a manual spawner withdrawal GUI.

This source line is not eligible for stable publication until the live PlexonCraft runtime gate is complete. See `.release/RELEASE_NOTES_4.0.0.md` and `docs/MIGRATION_4_0.md`.
