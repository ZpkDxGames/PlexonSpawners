# PlexonSpawners 4.0.0 — WildStacker Authority + Administrator Policy GUI

PlexonSpawners 4.0.0 keeps WildStacker as the exclusive stack engine while expanding Plexon-owned recovery/reward policy and administration.

The 4.0 candidate now includes `/pspawners admin`, draft-based configuration editing, Essence/custom non-Silk reward modes, independent per-logical-unit rolls, per-mob overrides, safe config backup/atomic save behavior, stale-session protection and the existing WildStacker-authoritative withdrawal GUI.

This source line is **not eligible for stable publication until the live PlexonCraft runtime gate is complete**. Runtime and migration status must never be inferred from CI. See `.release/RELEASE_NOTES_4.0.0.md`, `docs/ADMIN_GUI.md`, and `docs/MIGRATION_4_0.md`.
